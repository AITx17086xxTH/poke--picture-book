# ポケモン図鑑（PokéAPI × React）

ポートフォリオ用に制作した、ポケモン図鑑＋パーティ編成アプリです。

## 制作の目的
- Reactと TypeScript の実践的な学習
- 外部API連携と、Firebaseによる認証・データ保存の経験

## 主な機能
### フェーズ1：図鑑
- ポケモン一覧表示
- 名前検索
- タイプ・世代での絞り込み
- 詳細ページ（能力値・タイプ・特性など）

### フェーズ2：パーティ編成
- 最大6匹までのパーティ編成（お気に入りを兼ねる）
- ブラウザ内への保存

### フェーズ3：ログイン・クラウド保存
- Googleログイン／メール＋パスワードログイン
- ログインユーザーごとにパーティを保存

### フェーズ4：仕上げ
- スマホ対応（レスポンシブデザイン）
- ローディング表示・エラー表示
- 無料枠での公開

## 非機能要件
- スマホでも見やすい
- 通信失敗時も画面が壊れない
- すべて無料の範囲で運用
